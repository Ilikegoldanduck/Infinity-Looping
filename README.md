[Version 0.1]
 - Started Project
 - Added values (Temporary Names):
   - Alpha - The baseline currency, it can be obtained by clicking the button (RL[Reset Layer] 1) (The first star)
   - Beta - Another baseline currency, it can be obtained by clicking another button that resets alpha (RL 2) (The second star)
   - Gamma - You gain this currency per second if you have Beta (increaseable) (RL 2)
   - Delta - After clicking the button for this currency, you have to wait a set amount of time before you gain the currency and is able to click it again (RL 2) (The third star)
   - Epsilon - This currency is gained per second as long as you have Delta (non increaseable) (RL 2)
   - Zeta - A third currency that gets their multiplier off of: Beta (as the main), Epsilon (2 - e^Epsilon) and Delta (log 10 (Delta + 1) + 1) (RL 3)
